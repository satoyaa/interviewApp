## 環境構築手順
### 1．各種ツールの準備（Node.js，Pythonのインストール）
プロジェクトを動かすためには，パッケージ管理ツール（npm，pip）と実行環境が必要です．インストールされていない場合は，以下を参考に導入してください．

* Node.js (npm): フロントエンド（React）の環境構築と実行に必要です．

  * Node.js公式サイトから「LTS（推奨版）」をダウンロードし，インストールしてください．インストール後，自動的にnpmコマンドが使えるようになります．

* Python (pip): バックエンド（FastAPI）の環境構築と実行に必要です．

  * Python公式サイトから最新の安定版をインストールしてください．インストール時，「Add Python to PATH」という項目に必ずチェックを入れてください．

(※コマンドプロンプトやターミナルを開き，node -v と python --version を実行してバージョンが表示されれば準備完了です．)

### 2．ライブラリのインストール
フロントエンドとバックエンド，それぞれで必要なパッケージをインストールします．

**フロントエンド（React + Vite）**

フロントエンドのディレクトリに移動し，以下のコマンドを実行します．
```
Bash
cd <フロントエンドのディレクトリ名>
npm install
```

**バックエンド（FastAPI）**

バックエンドのディレクトリに移動し，Pythonの仮想環境を作成してからパッケージをインストールします．
```
Bash
cd <バックエンドのディレクトリ名>
# 仮想環境(venv)の作成
python -m venv venv

# 仮想環境のアクティベート
# Windowsの場合
venv\Scripts\activate
# Mac/Linuxの場合
# source venv/bin/activate

# 必要なライブラリのインストール
pip install -r requirements.txt
```

### 3．環境変数の設定（.envファイルの作成）
APIキーやシークレットキーなどの機密情報はGitの管理外（.gitignoreに登録済み）となっています．
各自のローカル環境で，以下の指定された場所に .env ファイルを新規作成し，必要な値を設定してください．

**フロントエンド側 .env**

* 作成場所: フロントエンドのルートディレクトリ（package.json と同じ階層）
* 記載内容:

```
コード スニペット
VITE_GOOGLE_CLIENT_ID="取得したGoogle Client IDを入力"
```
**バックエンド側 .env**
* 作成場所: バックエンドのルートディレクトリ（requirements.txt と同じ階層）
* 記載内容:

```
コード スニペット
GEMINI_API_KEY="取得したGemini APIキーを入力"
GOOGLE_CLIENT_ID="取得したGoogle Client IDを入力"
SECRET_KEY="システムで設定されたシークレットキーを入力"
ALGORITHM="HS256" # 使用する暗号化アルゴリズム（例: HS256）
```
### 4．ローカルサーバーの起動とデータベースについて
環境構築と設定が完了したら，以下のコマンドでサーバーを起動し，動作確認を行ってください．

**バックエンドの起動**

仮想環境がアクティベートされた状態で，以下のコマンドを実行します．（※ main:app の部分は，エントリーポイントとなるPythonファイル名に合わせて適宜読み替えてください）

```
Bash
uvicorn main:app --reload
```
**フロントエンドの起動**

フロントエンドのディレクトリで以下のコマンドを実行します．
```
Bash
npm run dev
```
**データベース（SQLite）について**

SQLiteのデータベースファイル（例: app.db）は，バックエンドの初回起動時やマイグレーション処理の実行時にローカルフォルダ内に自動生成されます．データベースサーバーの別途インストールや構築は不要です．
